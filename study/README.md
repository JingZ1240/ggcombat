# Study Scripts

This directory contains public study scripts that support the GG-ComBat
manuscript without distributing restricted data or private manuscript artifacts.

The public repository keeps:

- simulation scripts for the main manuscript setting;
- parameter-recovery simulation scripts;
- reviewer-requested robustness simulation scripts;
- runtime notes.

The public repository does not include:

- raw ABCD data;
- subject-level derived ABCD files;
- executable ABCD application workflows tied to private input paths;
- manuscript source files or private response materials;
- exploratory notebooks and development provenance snapshots.

This separation is intentional. The Associate Editor requested a documented code
implementation to improve usability and impact. The public repository therefore
prioritizes the reusable R package, tests, examples, and simulation settings,
while respecting restricted-data and manuscript-review boundaries.
