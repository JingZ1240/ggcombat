# Revision Simulation Scripts

Planned scripts for the AOAS revision:

1. `01_operating_range.R`: stronger additive and covariance site effects.
2. `02_block_coherence.R`: gradual violation of block-coherent site effects.
3. `03_community_misspecification.R`: true, estimated, perturbed, and random memberships.
4. `04_nonlinear_covariates.R`: linear versus nonlinear biological covariate effects.
5. `05_block_combat_baseline.R`: blockwise ComBat comparator.
6. `06_runtime_benchmark.R`: practical computation time table.

Keep generated results under `paper/simulations/results/`, which should not be
committed until privacy and file-size constraints are checked.
